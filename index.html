Product · WorkHub · Project tool for a small team

From $3.31 to $0.33 a report.

Prototype · Clinic receptionist

About ₹3 a call to run.

A voice receptionist for clinics that answers calls in Hindi, Hinglish or English and books the appointment slot. Across nine live test calls, each call cost ₹2.85 to ₹3.20 to run, before GST.

Technical note. I don’t write code by hand: I scope each product, direct Claude Code and test what it builds. Role Radar runs on TypeScript, Next.js and Neon Postgres, with Gemini 2.5 Flash and the Anthropic SDK, Resend for email and GitHub Actions for the daily run.
